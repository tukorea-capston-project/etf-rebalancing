# 전략 스키마 규칙

상세 설계는 `docs/strategy-schema.md`를 따른다. 스키마나 검증 로직을 바꾸기 전에 그 문서를 읽고, 설계가 바뀌면 문서도 함께 고친다.

- 전략은 자산군·현금 비중, 묶음, 직접 지정한 종목, 리밸런싱 조건, 금액을 담는다. 시장 신호에 따라 비중을 바꾸는 조건은 스키마에 넣지 않는다(국면 대응은 거시판단 운용이 한다).
- LLM은 카탈로그 안에서 값을 고르고 설명 문장만 쓴다. 비중, 종목코드 같은 숫자는 코드가 계산한다.
- 비중은 1%p 단위 정수, 합계 100%(현금 포함). ETF는 최대 10개, 종목당 최소 5%. 현금은 종목 수·최소 비중 제약의 예외다.
- 밴드는 "절대 폭과 상대 폭 중 좁은 쪽"으로 계산한다.
- 사용자가 지정한 ETF, 자산군 비중, 현금 비중은 포트폴리오 생성과 국면 전환에서 바꾸지 않는다.
- 전략은 덮어쓰지 않고 새 버전으로 저장한다. 국면 전환은 전략 버전을 만들지 않고 운용 상태와 전환 이력에 기록한다.
