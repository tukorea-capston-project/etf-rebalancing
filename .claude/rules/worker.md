# 워커 규칙

이 폴더를 고치기 전에 `docs/architecture.md`를 읽습니다. 로직은 그 문서에만 쓰고, 설계가 바뀌면 그 문서를 고칩니다. 아래는 어기면 사고가 나는 규칙입니다. 예약 작업 워커와 백테스트 워커를 EC2에서 각각 하나만 실행하는 규칙은 CLAUDE.md 실행 환경에 있습니다.

- 워커에는 예약 작업 시각표와 백테스트 대기열 처리만 둡니다. 도메인 로직은 두지 않고 각 도메인의 `service.py` 함수를 부릅니다.
- API 서버와 워커는 서로 직접 호출하지 않고 DB로만 주고받습니다.
- 시각은 한국 시간(KST) 기준입니다. 서버의 시스템 시간대에 기대지 않습니다.
- 예약 작업과 백테스트 대기열을 한 프로세스에 넣지 않습니다. 백테스트가 주문·계산 시각을 밀어냅니다.
- 놓친 예약 작업은 유효 시각 안에서만 실행하고, 놓친 날짜를 몰아서 처리하지 않습니다(`docs/architecture.md` 놓친 작업과 재시작).
