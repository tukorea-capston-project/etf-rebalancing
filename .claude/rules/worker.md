# 워커 규칙

상세 설계는 `docs/architecture.md`를 따릅니다. 로직을 바꾸기 전에 그 문서를 읽고, 설계가 바뀌면 문서도 함께 고칩니다.

- 워커에는 예약 작업 시각표와 백테스트 대기열 처리만 둡니다. 도메인 로직은 두지 않고 각 도메인의 `service.py` 함수를 부릅니다.
- 예약 작업과 백테스트 대기열은 워커에서만 실행합니다. API 서버(`main.py`, 각 `router.py`)에 스케줄러나 백그라운드 작업을 넣지 않습니다.
- 워커는 EC2에서 하나만 실행합니다. 팀원 PC의 API 서버도 서비스 DB에 붙으므로, 여러 곳에서 돌면 수집·주문이 중복됩니다.
- API 서버와 워커는 서로 직접 호출하지 않고 DB로만 주고받습니다.
- 시각은 한국 시간(KST) 기준입니다. 서버의 시스템 시간대에 기대지 않습니다.
