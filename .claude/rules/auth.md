# 사용자·인증 규칙

이 폴더를 고치기 전에 `docs/auth.md`를 읽습니다. 로직은 그 문서에만 쓰고, 설계가 바뀌면 그 문서를 고칩니다. 아래는 어기면 사고가 나는 규칙입니다.

- 비밀번호는 해시로만 저장합니다. 원문을 DB, 로그, 예외 메시지, API 응답에 남기지 않습니다.
- 모드, KIS 자격 증명, 정지 상태, 전략, 포트폴리오를 조회·수정할 때 소유자를 검사합니다. 다른 사용자의 데이터에 접근할 수 없어야 합니다.
- 세션 쿠키는 `HttpOnly`, `Secure`로 둡니다.
- CORS를 열거나 크로스 도메인 쿠키(`SameSite=None`)를 쓰지 않습니다. 프론트엔드와 API는 같은 오리진입니다.
