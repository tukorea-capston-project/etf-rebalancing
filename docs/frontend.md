# 화면 설계

사용자 화면에서 무엇을 보여 주는지 정의합니다. 코드 구현은 `frontend/`에 둡니다.
화면에 보여 주는 값의 계산 규칙은 각 기준 문서를 따르고, 이 문서에서는 다시 설명하지 않습니다.
알림은 화면이 아니라 이메일로 보냅니다(`docs/trading.md` 알림).

## 계정

### 회원가입·로그인

- 각자 계정으로 전략과 운용 기록을 따로 관리합니다.
- 로그인 방식과 데이터의 소유 관계는 `docs/auth.md`를 따릅니다.

## 전략 만들기

### 자연어 입력

- 원하는 포트폴리오를 문장으로 말합니다. 비중이나 종목을 말하지 않아도 됩니다.
- 문장을 전략으로 바꾸는 방법은 `docs/strategy-schema.md` 자연어 → 전략 변환을 따릅니다.

### 되묻기

- 빠진 필수 값(리밸런싱 조건, 투자 금액)을 선택지로 묻습니다(`docs/strategy-schema.md` 필수 값과 되묻기).
- 규칙에 어긋난 요청은 이슈 단계에 따라 이유, 바뀐 부분, 선택지, 경고를 보여 줍니다(`docs/strategy-schema.md` 이슈 4단계, 표현할 수 없는 요청).

### 리밸런싱 조건 설정

- 주기·비중 이탈 밴드·혼합 중 하나와 그 주기·밴드 폭을 정하고, 초기 투자금과 매월 적립금을 정합니다.
- 고를 수 있는 값은 `docs/strategy-schema.md` 리밸런싱 조건과 금액을 따릅니다.

### 전략 확인

전략은 사용자가 확인해야만 확정됩니다(`docs/strategy-schema.md` 확정, 승인, 버전 관리).

- 시스템이 이해한 내용과 만들어진 포트폴리오(묶음별 대표 ETF와 비중)를 문장으로 보여 줍니다.
- 전략을 다이어그램으로 바꿔 한눈에 확인하게 합니다.
- 칸마다 사용자가 말한 값, 계산한 값, 기본값을 구분해 보여 줍니다(`docs/strategy-schema.md` 칸과 출처).

### 블록 애니메이션

- 포트폴리오가 만들어지는 과정을 블록이 쌓이는 애니메이션으로 보여 줍니다.
- 만들어지는 과정은 `docs/strategy-schema.md` 포트폴리오 생성의 절차를 따릅니다.

## 백테스트

### 백테스트 결과

- 고정비중 운용과 거시판단 운용 두 결과를 기본으로 보여 줍니다. 두 운용 방식과 성과 지표는 `docs/backtest.md` 대상, 성과 지표를 따릅니다.
- LLM 지표를 뺀 거시판단 운용은 토글을 켰을 때만 보여 줍니다(`docs/backtest.md` LLM 지표와 미래 정보).
- 거시판단이 작동한 기간을 표시합니다. 국면 지표가 모자란 초기 구간은 거시판단이 꺼져 있습니다(`docs/backtest.md` 대상).
- 백테스트 속 비중과 사용자가 확인한 전략 비중을 함께 보여 줍니다. 둘이 다를 수 있는 이유는 `docs/backtest.md` 투자 대상: 시점별 선정을 봅니다.

### 승인

- 결과를 보고 운용을 시작하거나, 문장을 고쳐 다시 만듭니다(`docs/strategy-schema.md` 확정, 승인, 버전 관리).

## 운용

### 모드와 KIS 자격 증명

- 모의·실전 각각의 KIS 자격 증명을 등록하고 삭제합니다. 자격 증명을 보여 줄 때는 `docs/trading.md` 노출 금지를 따릅니다.
- 전환 버튼으로 모의·실전 모드를 바꿉니다. 실전으로 바꿀 때는 비밀번호를 다시 입력하고 경고를 확인합니다. 전환 조건은 백엔드가 검사합니다(`docs/trading.md` 모드 전환).

### 운용 현황 대시보드

- 평가액, 수익률, 현재 비중과 현재 목표 비중, 리밸런싱·주문 기록을 보여 줍니다.
- 평가액과 현재 목표 비중의 뜻은 `docs/rebalancing.md` 용어, 주문은 `docs/trading.md`를 따릅니다.

### 구성종목 그래프 뷰

- 보유 ETF가 실제로 어떤 종목을 담고 있는지 그래프로 보여 줍니다.
- 구성종목 데이터의 수집은 `docs/market-data.md`를 따릅니다.

### 안전장치

- 긴급 중지 버튼으로 자동 주문을 즉시 멈춥니다.
- 정지 상태와 정지 사유(이상 감지 / 긴급 중지 / 서버 스위치)를 보여 주고, 사용자가 직접 재개합니다.
- 이상 감지의 사용자 기준을 정합니다.
- 동작과 조건은 `docs/trading.md` 안전장치를 따릅니다.

## 거시판단

### 국면·전환 이력

- 현재 국면과 국면 지표의 상태를 보여 줍니다.
- 국면이 바뀌었을 때 바뀐 ETF·비중과 그 이유(어떤 지표가 기준을 넘었는지)를 보여 줍니다. 전환 이력의 내용은 `docs/macro.md` 국면 전환을 따릅니다.

### 공포 경고

- 투자심리가 공포 국면일 때 사용자가 계획에서 벗어난 매도(전략 중지, 비중 직접 축소)를 하려 하면 경고를 보여 줍니다.
- 경고 조건은 `docs/macro.md` 투자심리 공포와 경고를 따릅니다.

## 미정

- 화면 목록(페이지 구성)과 화면 사이의 흐름
- 전략 다이어그램의 형태(무엇을 노드로 두고 어떻게 잇는지)
- 블록 애니메이션에서 블록 하나가 나타내는 단위(묶음, ETF 등)와 보여 줄 단계
- 구성종목 그래프 뷰의 그래프 형태, 여러 ETF가 같은 종목을 담을 때 합쳐 보여 줄지
- 운용 현황 대시보드의 수익률 기준(기간, 적립금 반영 방식)
