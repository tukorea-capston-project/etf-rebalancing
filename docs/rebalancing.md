# 리밸런싱 설계

전략(`docs/strategy-schema.md`)이 정한 조건에 따라, 언제 무엇을 얼마나 사고팔지 정의한다.
코드 구현은 `backend/app/portfolio/`에 둔다. 백테스트와 모의투자는 같은 리밸런싱 로직을 쓴다.

## 용어

| 용어 | 의미 |
|---|---|
| 계산일 | 리밸런싱 여부와 주문 수량을 계산하는 날 |
| 평가액 | 보유 ETF를 계산일 종가로 평가한 금액 + 현금 |
| 목표 금액 | 평가액 × 현재 목표 비중 |
| 부족분 / 초과분 | 목표 금액 − 현재 금액이 양수면 부족분, 음수면 초과분 |

현금도 하나의 자산이다. 현금의 목표 비중도 부족분·초과분 계산에 포함한다.

## 시점

- 계산일 장 마감 후 **당일 종가**로 계산하고, **다음 영업일**에 주문한다. 계산에는 계산일 종가까지의 정보만 쓴다. 백테스트에서 미래 정보를 쓰지 않게 하려는 것이다.
- 계산일이 되는 날
  - 주기 리밸런싱일: 전략에 정한 일자. 휴장일이면 다음 영업일.
  - 밴드 확인일: 매주 마지막 영업일.
  - 적립일: 전략에 정한 매월 일자. 휴장일이면 다음 영업일.
  - 거시판단 제안 수락일: 사용자가 "지금 리밸런싱"을 고른 경우.

## 리밸런싱 종류

| 종류 | 언제 | 무엇을 |
|---|---|---|
| 전체 리밸런싱 | 주기 리밸런싱일, 제안 수락 후 "지금 리밸런싱" | 모든 자산을 목표 금액으로 |
| 밴드 리밸런싱 | 밴드 확인일에 밴드를 벗어난 자산이 있을 때 | 벗어난 자산만 목표 금액으로, 차액은 다른 자산에서 조정 |
| 적립금 매수 | 적립일 | 매도 없이 적립금으로 부족한 자산을 매수 |

- 전략의 리밸런싱 조건에 따라 위 종류 중 무엇이 일어나는지 정해진다.
  - 주기: 주기 리밸런싱일에 전체 리밸런싱
  - 밴드: 밴드 확인일마다 밴드 리밸런싱
  - 주기 + 밴드 혼합: 주기 리밸런싱일에만 밴드를 확인하고, 벗어난 자산이 있으면 밴드 리밸런싱
- 적립금 매수는 조건 설정과 관계없이 **항상** 적용하는 고정 규칙이다.

### 같은 날 여러 종류가 겹칠 때

적립금을 먼저 현금에 더한다. 그다음 그날 해당하는 종류 중 가장 범위가 넓은 것 하나만 계산한다.
범위는 **전체 > 밴드 > 적립금 매수** 순서로 넓다. 주문은 한 묶음으로 나간다.

## 목표 금액 계산

### 전체 리밸런싱

모든 자산의 목표 금액 = 평가액 × 목표 비중.

### 밴드 리밸런싱

1. 밴드를 벗어난 자산을 목표 금액으로 맞춘다. 밴드 계산은 `docs/strategy-schema.md`의 5/25형을 따른다.
2. 위로 벗어난 자산과 아래로 벗어난 자산이 함께 있으면, 위로 벗어난 자산을 판 돈으로 아래로 벗어난 자산을 먼저 채운다. 서로 상쇄하고 남은 차액만 3단계로 넘긴다.
3. 남은 차액을 밴드 안의 나머지 자산(현금 포함)에서 조정한다.
   - **초과분을 팔아 남은 돈**은 부족한 자산부터 채운다.
     - 돈이 모든 부족분을 채우기에 모자라면 **부족분 비율대로** 나눈다.
     - 다 채우고도 남으면 나머지는 목표 비중 비율로 나눈다.
   - **부족분을 사기 위한 돈**은 초과 자산부터 팔아 마련한다.
     - 초과분 합계로 모자라지 않으면 **초과분 비율대로** 판다.
     - 초과분을 다 팔아도 모자라면 나머지는 목표 비중 비율로 판다.

예시: 목표 A 40 / B 30 / C 20 / 현금 10, 현재 A 47 / B 26 / C 18 / 현금 9.
밴드 5%p/25%이면 A만 밴드(35~45%)를 벗어났다. A를 40%로 맞추면 7%p가 남는다.
B 4, C 2, 현금 1의 부족분을 채우면 모두 목표가 되고, 남는 돈은 없다.

### 적립금 매수

적립금은 부족한 자산부터 매수한다. 매도는 하지 않는다.
돈이 부족분을 모두 채우기에 모자라면 부족분 비율대로, 다 채우고도 남으면 목표 비중 비율로 나눈다.

## 주문 수량 계산

ETF는 1주 단위로만 거래한다.

1. 각 ETF의 목표 수량 = 목표 금액 ÷ 계산일 종가, **내림**.
2. 현재 수량과의 차이로 매도·매수 수량을 정한다.
3. 내림으로 남은 현금으로 **1주씩 추가 매수**하되, 사면 포트폴리오가 목표에 더 가까워질 때만 산다.
   - "목표와의 거리" = 모든 자산(현금 포함)의 |현재 비중 − 목표 비중| 합계(%p).
   - 보유 현금으로 살 수 있는 ETF 중 1주를 샀을 때 거리가 가장 많이 줄어드는 것을 산다.
   - 어느 것을 사도 거리가 줄지 않거나, 살 수 있는 ETF가 없으면 멈춘다.
   - 현금 목표 아래로 내려가는 매수도, 거리가 줄어든다면 허용한다.

   예시: 평가액 1,000만 원, 목표 A 50 / B 40 / 현금 10, 가격 A 30만·B 7만.
   - 내림 결과: A 16주(48%), B 57주(39.9%), 현금 12.1%. 거리는 2 + 0.1 + 2.1 = 4.2.
   - A 1주를 사면 거리 2.0, B 1주를 사면 거리 4.0이다. 더 많이 줄어드는 A를 산다.
   - 결과: A 51%, B 39.9%, 현금 9.1%.
   - 여기서 B를 더 사면 거리가 3.2로 늘어나므로 멈춘다.
4. 최소 주문 금액 제한은 두지 않는다. 1주라도 주문한다.
5. 매도를 먼저 하고 그 대금으로 매수한다.

## 분배금

분배금은 전략의 리밸런싱 조건과 관계없이 **항상 그 분배금을 준 ETF에 재투자**한다.

| 구분 | 재투자 시점 |
|---|---|
| 백테스트 | 분배락일. 표준 총수익률 계산 방식이다. |
| 모의투자 | 분배금이 입금된 다음 영업일 |

모의투자는 실제 지급일에 돈이 들어오므로 분배락일에 재투자할 수 없다. 그래서 백테스트와 모의투자 결과는 이 차이만큼 조금 다를 수 있다.

## 거시판단 제안 수락

- 제안을 수락하면 전략의 새 버전이 만들어진다(`docs/strategy-schema.md`).
- 수락할 때 사용자가 리밸런싱 시점을 고른다.
  - **지금 리밸런싱**: 수락한 날을 계산일로 보고 새 목표 비중으로 전체 리밸런싱한다.
  - **다음 조건 때**: 목표 비중만 바꾸고, 다음 주기·밴드·적립 계산일에 반영한다.

## 미정

- 체결 가격 가정(백테스트에서 다음 영업일 시가/종가 중 무엇으로 체결할지): 백테스트 문서에서 다룬다.
- 수수료·슬리피지를 주문 수량 계산에 어떻게 반영할지(매수 시 수수료만큼 현금을 남길지 등)
- 백테스트에서 분배금이 1주 가격보다 작을 때 처리(소수점 수량 허용 여부 등)
- 모의투자 주문 방식(지정가/시장가, 미체결 처리): 모의투자 문서에서 다룬다.
