# ETF 리밸런싱 시스템

자연어로 말한 투자 요구를 전략으로 바꾸고, 그 전략대로 국내 ETF 포트폴리오를 리밸런싱하는 시스템입니다.

> 예: "100만원 있는데 2년 뒤에 전세금 보탤 돈이에요. S&P 그거 넣어주시고 반도체도 조금 넣어주세요"
> → 빠진 값(리밸런싱 조건 등)만 되묻고, 선정 조건을 통과한 ETF로 종목·비중을 계산한 뒤, 사용자가 확인하면 전략으로 확정합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 자연어 → 전략 변환 | 로컬 LLM이 사용자 메시지를 정해진 형식으로 해석합니다. 사용자가 확인해야 전략으로 확정합니다 |
| 포트폴리오 구성 | 사용자가 말한 값은 그대로 두고, 나머지는 묶음별 대표 ETF(minimax)와 HRP 비중으로 계산합니다 |
| 백테스트 | 과거 시세로 고정비중 운용과 거시판단 운용을 비교합니다. 분배금 재투자, 수수료·슬리피지·세금을 반영합니다 |
| 모의·실전투자 | 한국투자증권(KIS) Open API로 자동 주문합니다 |
| 리밸런싱 | 사용자가 정한 주기·비중 이탈 밴드·혼합 조건에 따라 목표 비중으로 되돌립니다 |
| 거시판단 운용 | 매주 국면(금리·미국 금리·환헤지·위험선호)을 판단하고, 국면이 바뀌면 묶음별 ETF를 자동으로 다시 고르고, 시장이 불안하거나 좋을 때는 위험자산 비중을 조절합니다 |

## 운영 범위

**백테스트 → 모의투자 → 실전투자** 순서로 진행합니다. 여러 사용자가 각자 KIS 계좌를 등록해 쓰는 실제 서비스로 배포할 수 있게 만드는 것이 목표입니다.
